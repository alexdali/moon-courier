# Contributing

Этот репозиторий прежде всего является стартовой базой тестового проекта. Изменения лучше делать небольшими и проверяемыми.

## Перед изменением

1. Прочитать `docs/ARCHITECTURE.md` и соответствующий ADR в `docs/decisions/`.
2. Не помещать SQL, HTTP и AI-вызовы в `src/domain`.
3. Не позволять клиенту вычислять результат доставки.
4. Не использовать LLM для чисел, которые может рассчитать детерминированный код.

## Локальная проверка

```bash
npm install
npm run validate
npm run build
```

Для изменения доменной формулы обязательны:

- unit-тест;
- property-based тест, если есть монотонный инвариант;
- обновление `docs/FORMULAS.md`;
- повторный `npm run simulate`.

Для изменения AI-контракта обязательны:

- обновление JSON Schema/Zod;
- тест primary success;
- тест primary rejection → Luna;
- сохранение прежнего deterministic gate;
- обновление `docs/AI_PIPELINE.md`.

## Pull request

В PR укажите:

- какую проблему решает изменение;
- какие инварианты затрагивает;
- какие команды выполнены;
- скриншот для UI-изменения;
- возможный риск и способ отката.
