# Security policy

Подробная модель угроз находится в [`docs/SECURITY.md`](docs/SECURITY.md).

Не публикуйте в issue:

- `OPENROUTER_API_KEY`;
- содержимое `.env`;
- production database;
- токены deployment-платформы.

Для приватного сообщения об уязвимости используйте закрытый канал владельца репозитория. В публичном тестовом репозитории не включайте реальные секреты даже временно.
