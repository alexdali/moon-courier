# ADR-0005: SVG tactical map

- Status: Accepted
- Date: 2026-08-14

## Context

Карта является главным визуальным элементом, но полноценный 3D/GIS-движок не нужен для небольшого графа.

## Decision

Использовать responsive SVG: граф, зоны, маркеры, маршруты и replay анимируются React/CSS.

## Consequences

Карта быстро реализуется, хорошо масштабируется и остаётся доступной. При сотнях объектов или сложной камерной навигации потребуется Canvas/WebGL adapter, но доменная модель графа сохранится.
