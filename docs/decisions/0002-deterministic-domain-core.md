# ADR-0002: Deterministic domain core

- Status: Accepted
- Date: 2026-08-14

## Context

Вес, батарея, скорость, риск и экономика являются критериями задания и должны быть проверяемыми.

## Decision

Все числовые правила и переходы состояния реализуются чистыми TypeScript-функциями. Случайность передаётся как seed. AI не имеет права вычислять или менять игровое состояние.

## Consequences

Формулы тестируются без API и БД, а доставка воспроизводится. Придётся явно проектировать DTO между LLM и инструментами вместо прямого «пусть агент всё решит».
