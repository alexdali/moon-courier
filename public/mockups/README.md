# Moon Courier Crisis — HTML-мокапы

Интерактивный набор HTML-мокапов по концепции **Lunar Mission Control / Tactical Logistics Interface**.

## Как запустить

### Быстрый вариант

Открыть `overview.html` для галереи всех экранов или `index.html` для немедленного запуска интерактивного Mission Control.

### Через локальный сервер

```bash
cd moon-courier-html-mockups
python -m http.server 8080
```

Затем открыть `http://localhost:8080`.

## Основные экраны

- `overview.html` — галерея и быстрый вход во все мокапы.
- `index.html` — главный Mission Control: карта, заказы, роверы, расчёт пары «заказ — ровер», AI Mission Control, журнал событий, невозможный сценарий и интерактивный запуск доставки.
- `scenario.html` — AI Scenario Architect: генерация мира из текстового запроса, параметры сложности, карта-превью и детерминированная валидация.
- `analytics.html` — Mission Debrief: KPI, экономика, причины провалов, загрузка роверов, сравнение сценариев и аналитический AI-вопрос.
- `delivery-success.html` — полный экран успешной доставки.
- `delivery-failure.html` — полный экран неудачной доставки с AI-разбором и контрфактической альтернативой.

## Что можно проверить в прототипе

На главном экране:

1. Выбрать разные заказы и роверы.
2. Выбрать `HAB-021`, чтобы увидеть обязательный невозможный сценарий.
3. Нажать `Recommend dispatch`, `Explain blockers` или `Simulate alternative`.
4. Переключить облачную и локальную AI-модель кнопкой в шапке.
5. Запустить допустимую доставку — маршрут, ровер и журнал событий будут обновляться, затем появится результат.
6. Использовать фильтры и поиск заказов.

На экране Scenario Architect:

1. Выбрать preset или изменить prompt.
2. Настроить сложность, дефицит, волатильность и риск.
3. Нажать `Generate & validate`.
4. Увидеть последовательность AI-генерации и детерминированных проверок.

На экране аналитики:

1. Переключать период анализа.
2. Запустить 500 симуляций.
3. Скрыть/показать evidence.
4. Задать вопрос про прибыль, батарею, риск или узкое место флота.

## Технические свойства

- Только HTML, CSS и JavaScript.
- Без сборщика и внешних библиотек.
- Без сетевых запросов и внешних ассетов.
- Все иконки — локальный SVG-спрайт.
- Основное целевое разрешение — 1440×900.
- Есть адаптивные состояния для более узких экранов.
